1. Preparar la autoridad certificadora

Crea la CA local una sola vez. Esta firma los certificados de los usuarios.

2. Registrar usuario

Cada usuario recibe una clave pública y una privada (par RSA) y un certificado firmado por la autoridad certificadora (CA).

La clave privada se mostrará en pantalla. Quien la obtenga puede suplantar al usuario; úsala solo para la demostración.


      

      

        
3. Enviar mensaje

        
El mensaje se firma para comprobar quién lo envió y se cifra para que solo el destinatario pueda leerlo.

        
        
        
        

        
      

      

        
4. Recibir y verificar

        
La recepción comprueba el certificado, descifra el mensaje y verifica su huella (hash) y firma digital.

      Explorar los módulos de criptografía
      

        
Ejercicios independientes para observar cada operación. Sus claves son temporales y distintas de las que usan los usuarios.

        

          Glosario rápido
          

            
Hash (SHA-256)
Huella de longitud fija que permite detectar si un contenido cambió.

            
Firma digital
Prueba verificable de que una clave privada autorizó un contenido; no lo cifra.

            
Cifrado híbrido
Combina cifrado simétrico para el mensaje y cifrado de clave pública para proteger la clave de sesión.

            
Nonce / IV
Valor único que acompaña al cifrado. Con AES-GCM no se debe repetir con la misma clave.

            
Ciphertext
El mensaje cifrado, que no se puede leer sin la clave adecuada.

            
AAD
Datos autenticados junto al mensaje, pero que permanecen visibles y no se cifran.

            
RSA-OAEP
Esquema que cifra la clave AES de sesión para que solo el destinatario pueda recuperarla con su clave privada.

            
Certificado X.509
Documento firmado por una autoridad que vincula una identidad con una clave pública.

          

        

        

      

        
Módulo 1 · Hash e integridad

        
Calcula SHA-256 y cambia un bit del primer byte para observar el efecto avalancha.

        
        

        
        

      

      

        
Módulo 2 · AES-256-GCM

        
Genera una clave, un nonce (valor único que acompaña al cifrado), el mensaje cifrado y su etiqueta de autenticación; luego descifra para comparar. No repitas un nonce con la misma clave GCM. La clave se muestra solo en este ejercicio.

        
        

        
        

      

      

        
Módulo 3 · Cifrado híbrido

        
Combina dos métodos: AES cifra el mensaje y RSA-OAEP (cifrado con clave pública) protege la clave de sesión temporal.

        
        

        
        

      

      

        
Módulo 4 · Firma digital

        
Firma el texto y prueba la verificación original y después de cambiar un bit.

        
        

        
        

      

      

        
Módulo 5 · Certificados X.509

        
Comprueba la firma de la autoridad, la vigencia y la identidad del certificado X.509 (documento que vincula una identidad con una clave pública).
